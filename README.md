# 🖥️ Windows Prank System

Windows için geliştirilmiş, HTA tabanlı eğlence ve görsel efekt uygulaması.

## 🚀 Özellikler

- ⚠️ Sahte Windows hata mesajları
- 🔵 Görsel mavi ekran (BSOD) efekti
- 😂 Eğlence amaçlı sistem şakaları
- 🛡️ Efektleri durdurma ve kapatma
- ⚙️ Merkezi kontrol sistemi

## 📂 Proje Dosyaları

- `kaos_ekrani.hta`
- `mavi_ekran.hta`
- `merkezi_sistem.hta`

## 💻 Gereksinimler

- Windows işletim sistemi
- HTA dosyalarını çalıştırabilen Windows ortamı

## ⚠️ Uyarı

Bu proje eğitim ve eğlence amacıyla geliştirilmiştir. Mavi ekran efektleri görsel simülasyondur. Gerçek sistem hatası oluşturmayı veya bilgisayara zarar vermeyi amaçlamaz.
